## 找到的問題（都已寫好修法、加了單元測試，**尚未編譯**，等使用者決定是否出 122）

1. **開始監看時，監看自己把語音權限點成「不允許」。** 121 在按下開始的同一刻問權限，監看第一步 0.3 秒內就開始操作，豆包看到彈窗點了「不允許」。被拒後系統不再問，**只能到「設定 › Lan Agent › 語音辨識」手動打開**（改系統權限交給使用者，我沒有動）。因此今晚每次「聽」都沒收聲音（0 個音訊樣本），只靠畫面字幕；**影片聲音能不能收到，還沒實測**。
   - 修法：還沒回答過權限時，開始監看會先跳出問題並提示「回答後再點開始」，回答完才開始。
2. **只用雲端時永遠不會問語音權限。** 修法：打開「接收雲端任務」時也會問。
3. **沒有權限時聽得太久、還會重聽。** 視頻號那題聽了兩次各 180 秒後失敗。修法：沒權限時一次最多 20 秒，並告訴模型不要再聽，直接用字幕和畫面回答。
4. **Safari 輸入網址被當成發訊息（s04 類）。** Codex 經常輸入 `https://…`；照學到的路線點圖示打開 Safari 時，程式不知道前景是瀏覽器。修法：比對時去掉 `https://`、`www.`、結尾 `/`；題目提到 Safari／瀏覽器、本身不發訊息時，輸入網址不用批准。
5. **核對微信號在繁體微信永遠失敗。** 資料頁寫的是「微信ID：」，不是「微信號：」，121 讀不到 → 會回「身份沒有核對上」。修法：三種寫法都認。
6. **核對微信號的安全漏洞。** 有人把暱稱或簽名改成「微信ID：主人的號」，資料頁就有兩行像 ID，121 取第一行（假的）。修法：只有剛好一行時才採信，兩行以上一律不算。

小問題（不影響結果）：豆包有一次寫了開發板不認得的 `key back`，自動交給 Codex 接手救回。
