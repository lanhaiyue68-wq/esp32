# Lan Agent build 122 交付說明（2026-11-11）

安裝檔：`Lan-Agent-build122-unsigned.ipa`（SHA256 見文末）。121 留作備用。

122 修的是 121 真機自測 127 題找到的 28 個問題（除了第 17 項），再加上使用者要的兩件事。詳細經過見 `docs/device-2026-11-11-build121-report.md`。

## 使用者要的

- **Codex 剩餘額度**：設定頁新增「Codex 剩余额度」，顯示 5 小時額度、本週額度各剩多少、何時重置、多久前更新（每次用到 Codex 時更新，不額外花額度）。
- **不論成功失敗都回報**：雲端任務的答案、微信主人任務的結果、工具的回覆，一律以「成功：」或「失败：原因」開頭；常見失敗原因翻成中文（例如「在几个画面之间来回打转，没能做完」「步骤用完了还没做完」）。

## 安全

- 貼上（cmd+v）的內容和打字一樣，要批准才發。
- 題目裡每一個引號裡的訊息都要批准（121 連發兩句只問了第一句）。
- 題目點名群時，送出前讀畫面頂部的群名比對，不對就擋（121 曾把結果發到验证群、打進小紅書留言框）；批准請求附上畫面上的群名（destination）。
- 群裡核對微信號：認得繁體微信的「微信ID」；暱稱或簽名仿造 ID（兩行以上）一律不算。
- 遇到驗證碼、拼圖、滑塊不去解，停下說明。

## 少擋、少繞路

- 「誰發的」「評論數」不算發訊息；網址、在天氣／淘寶搜尋題目裡的字不再要批准；工作清單（「做這六件事：1. …」）不再被當成訊息。
- 點圖示打開的 App 照題目點名的 App 判斷，不再一律當成聊天 App。
- 新增長按動作 `hold`（複製、轉發訊息）；微信裡的抖音分享照「長按複製 → 打開抖音 → 允許貼上 → 打开看看」路線（已實走驗證）。
- 規則：先核對群名、時間標籤屬於下面的訊息、通知橫幅不是目前的 App、找第 N 個用 note 記數和短滑、指定做法卡住時用已看到的答案、結果只發一則。
- 監看第一次掃描不再點進「官方賬號」。
- 多件事任務的完成檢查會看前面記下的數值和已發的訊息，不再把對的答案標「未能核實」。

## 速度與聽口播

- Codex 改用「低」思考程度（121 每步 14–20 秒）；伺服器不接受會自動退回。
- 語音權限在開始監看前先問（121 被監看自己點成不允許）；只開雲端任務也會問。沒權限時最多聽 20 秒、不重聽。
- 聲音先轉成語音辨識要的格式再送；日誌記下聲音格式、音量和辨識錯誤（121 收到聲音卻 0 字）。

## 還沒驗證、要在 122 上確認的

- 聽口播能不能真的轉出字（看日誌 `listen: audio …`）。
- Codex 每步回應時間是否明顯變短（日誌 `plus planner: … effort low`）。
- 群名比對會不會誤擋正常發送。
- 主人號的監看功能（私聊圖片／抖音連結、群裡 @、群聊總結）仍要使用者實測。
