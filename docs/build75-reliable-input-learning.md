# Build75: shared text fidelity and inspectable learning

The input changes apply to every AgentLoop task, including ordinary tasks where fastText is false. Text capability selects the existing exact clipboard route for multiline code, tabs and scripts outside the board keyboard. JSON-quoted DO type commands preserve literal quotes, backslashes, indentation and escaped newlines. Short supported input retains verified typing.

LearningView reads the same LessonBook and ExperienceStore used in model requests. Home, Settings and Privacy expose it. Optional lesson fields preserve old array compatibility while adding disable status, actual request/task reference counts and the latest referencing task/run. Review outcomes are persisted in a 24-record/32KB sidecar; no screenshot is added. Existing lesson/case bounds remain 400KB/256KB. Disabled learning stops collection and retrieval; stale asynchronous reviews cannot restore cleared or deleted data. Automatic lessons remain less certain than explicit user corrections, and uncertain measured operations are not labeled successes.

The journal distinguishes reviewing, saved/reinforced, no reliable lesson, skipped, failure and interruption. Failed/no-action/noisy tasks are explained without manufacturing successful routes. Opening the page performs no model request; eligible completed runs keep the existing single text-only review request (maximum 600 output tokens). This is retrieval-based experience memory, not training model weights.
