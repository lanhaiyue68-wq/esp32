## 二、要修的問題

1. 題目裡有「評論數、轉發數、留言數、誰發的」就被當成要發訊息、輸入要批准（s04、v02）。改成只認真正的發送說法（發一則、發到、發給、發送、回覆、留言給…）。

3. 視頻號看完要關掉，不要留浮動小窗。
4. 第一次做的組合題全程由 Codex 帶路、每步約 15 秒（s01 701 秒）；之後記住路線會快。

## 四、身分與權限（建議）

- 只讀的事（讀圖、讀數據、總結）：群裡主人 @ 就做；主人名字改成獨特的可避免誤觸發。
- 有後果的事（伺服器、GitHub、發激活碼）：只接受主人私聊＋口令；群暱稱可以被照抄，群裡不接。
- 刪除、部署這類危險操作：要再回一次「確認」才執行。

## 五、待使用者提供

1. 群裡 @ 的只讀工作，結果發回群裡還是私聊給你。
2. 激活碼怎麼產生、伺服器介面（網址、參數）、發給誰、要不要每次先問你。
3. GitHub 要做哪些事；伺服器要做哪些事。
