## 發現但這版不改
- 「最新 N 條」在本輪先發了訊息之後才讀，會把自己剛發的算進去（r131c c1 先做第 8 項才做第 2 項）：題目沒規定順序時很難判斷，先記下。
- 抖音搜單一中文字（猫）文字辨識認不出、反覆被擋（r131c c3 16 分鐘）：132 只加了提示「有字就按 Return 搜尋，不要再點輸入框重打」，要看下一輪。
- 修 T 仍待 132 的「stale plan: dropping …」日誌看作廢的是哪種動作。

- **Safari 每次都靠搜尋打開**：131 開了 10 次，平均 50 秒（其他 App 點圖示 8–18 秒）。Safari 在 Dock 裡，Dock 圖示沒有名字，讀主畫面認不出來。要嘛把 Safari 移到主畫面頁面上（測試機與客戶手機都一樣），要嘛做「用搜尋結果的圖示比對 Dock」——後者沒有 Mac 不敢盲寫。
- 過熱（thermal serious、背景被凍住）：**使用者 11-14 決定忽略**，正式投產會配散熱架；比較表只留次數當背景數據。
- 修 S（最新三條清單）：131 g1／g2／g4 第 2 項都對，還要看第二、三波。
