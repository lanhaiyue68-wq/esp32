# Mobinono iPhone Agent 演示对照（2026-10-27）

本次是视频分析，没有修改运行代码，也没有安装或连接新的手机控制工具。

## 证据与判断

- 原视频：https://www.douyin.com/video/7700558138902105395 ，时长约 60 秒。
- 已通过浏览器逐段查看开头、模型配置、设备连接、微信操作、设备管理及锁屏密码配置。离线视频下载未成功，因此未进行本地抽帧或音频转写。
- 画面包含 Windows 电脑端网页控制台、DeepSeek/GLM 模型配置、设备列表、微信输入与发送，以及手机浏览器中的设备管理。视频字幕声称无需安装手机 App，首次数据线连接并信任，后续同一网络可运行。
- 作者在评论中表示实测过三台并发，并提及每台设备对应隧道。该评论支持调试隧道方案的推测，但没有公布底层源码或依赖。
- 推测架构：电脑端 Agent + 已配对 iPhone 的调试服务/隧道 + 屏幕观察 + 输入控制。不能确定是 CoreDevice、WDA、蓝牙 HID 或组合；不能仅凭标签认定实际 GUI 模型或其智力水平。
- 可行性依据：pymobiledevice3 官方文档已提供隧道、CoreDevice 截图、虚拟触摸/键盘以及显示服务剪贴板能力。这些 API 的存在不能证明作者使用它们，系统版本与服务支持仍须实机确认。
- 本项目对照依据是日志 34 的一次失败运行：约 75.743 秒、13 次 actor 调用，伴随重复 Home、旧画面/过期计划、拼音核验与切 App 粘贴失败。不是正常任务平均耗时，也不是与视频同任务的对照基准。
- build 73 修复输入保留和误删回退，不能视为已经解决画面时延、整体轮数或控制通道差异。359 项测试和设备编译通过，尚未真机复测。
