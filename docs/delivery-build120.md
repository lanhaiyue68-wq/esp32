# Lan Agent build 120 交付說明（2026-11-11）

安裝檔：`Lan-Agent-build120-unsigned.ipa`（SHA256 見文末）。上一版 119 留作備用。

## 可以用的功能

- **雲端派任務（Wi-Fi）**：雲端派一句話任務，手機自己開 App、操作、讀結果，回報答案和完成那一刻的截圖。
  - 只有真的要發訊息才要批准；搜尋、開網址、開 App 不問。被拒的訊息不會發出，輸入框會清空。
  - 卡住時直接回報失敗和原因，不會停著等人。
  - 回傳的截圖會先把 IMEI、ICCID、序號、MAC 位址等裝置號碼塗黑。
  - 手機過熱到「危急」時，新任務先回 `retry_pending`（`device_hot`），最多延後 5 分鐘，涼了再接。
- **微信監看**：監看設定的會話；群裡被 @ 或帶暗號、私聊名單上的人，會自動回覆（帶手機當天日期）；名單外的群只讀不回，點開一次後 20 分鐘不再打開。
- **手機任務（私聊＋口令）**：主人私聊並帶口令時，可以讓手機去操作 App 再回報。

## 已知限制（不影響交付，之後再處理）

- 第一次做的新任務要靠 Codex（ChatGPT Plus）；Codex 額度用完時只剩豆包，難題成功率會下降（11-10 曾 429 一小時）。
- 豆包帳戶欠費時會 403，改由 Codex 接手；請定期查火山引擎餘額。
- 監看偶爾點進群後讀不到群名，會晚一輪才讀到；這時的畫面存在 App 的 Documents/diagnostics，方便查原因。
- 監看的群聊暗號以 Lan Agent 設定為準（程式預設「天王盖地虎」不一定是你的設定）。
- 連續跑很久時手機會發熱；建議不要放在密閉、悶熱的地方充電。

## 使用前確認

1. 開發板已連線、游標已校準、整個螢幕在共享（Lan Agent 首頁會顯示）。
2. 「要停止與 Lan Agent 共享螢幕嗎」一律點「取消」。
3. 雲端位址與 token 在設定裡填好；Wi-Fi 能連到雲端。
