# Lan Agent build 121 測試清單（2026-11-11）

121 一次加上微信助理的全部功能。以下每一項寫了「怎麼做」和「應該看到什麼」。微信只在**测试群、验证群**和主人私聊裡測。

> **夜裡自測後的更正（11-11）**：
> - 語音權限在自測時被監看自己點成了「不允許」：請先到 **設定 › Lan Agent › 語音辨識** 打開，不然聽口播只有字幕。
> - **121 的「群裡核對微信號」在繁體微信上會失敗**（資料頁寫「微信ID」），第 7、8 項先不要測；修法已寫好，等 122。

## 先設定（Lan Agent › 守候微信設定）

1. **名單**：會話填 `测试群`、`验证群` 和主人私聊；名單上的人填**這台手機給主人的備註**（例如「主人藍海樂」，別人看不到）；填好暗號和「我在微信的名字」（別人 @ 的那個）。
2. **主人任務**：「看圖、看視頻、讀鏈接、總結（只讀任務）」預設已開；「聽視頻的聲音（口播文案）」預設已開。**改過這個開關要重新共享螢幕。**
3. 第一次按「開始監看」，系統會問「語音辨識」權限 → 選**允許**（不允許就只讀得到畫面字幕）。
4. **自動盯著的群**（可選）：填一個群名，例如 `验证群`。
5. **群裡核對微信號**（可選）：打開後填主人的微信號（資料頁「微信號：」後面那串）。
6. **工具（主人專用）**：客戶還沒給 GitHub 和伺服器，先空著。

## 要測的項目

| # | 怎麼做 | 應該看到 |
|---|---|---|
| 1 | 主人私聊發一張圖片（不加字） | 先回「收到」，再回圖裡有什麼、圖上的文字 |
| 2 | 主人私聊發一條抖音分享連結（不加字） | 作者、標題或文案、點讚／評論／收藏／轉發數，加口播文案 |
| 3 | 主人私聊轉發一個視頻號影片 | 同上；看完會關掉，不留小窗 |
| 4 | 在测试群轉發一個影片，再 @它「這個視頻講了什麼」 | 總結 3–5 句和口播文案；太長會分幾則發 |
| 5 | 在测试群 @它「群裡最近在聊什麼」 | 一段總結（有存記錄就直接總結；記錄太少就自己往上翻再總結） |
| 6 | 在「自動盯著的群」裡發幾則訊息 | 不回覆；之後問第 5 項，會用到這些記錄 |
| 7 | 打開「核對微信號」後，主人號在群裡 @它看影片 | 它會先點主人頭像看資料頁，對上了才做 |
| 8 | 同上，換一個別的號（改同樣的群暱稱也行）@它 | 回「身份沒有核對上，這件事我不能做。」 |
| 9 | 群裡 @它「幫我在测试群發一句你好」（不帶暗號） | 不發；回一句說做不到（或請在私聊帶口令再說） |
| 10 | 雲端派「打開抖音第一個影片，告訴我是誰發的、評論和轉發各多少」 | **不會**跳出批准；直接回答 |
| 11 | 雲端派「打開抖音第一個影片，聽它講了什麼，給我口播文案」 | 回答裡有語音轉的文字或畫面字幕 |

## 已知限制

- **聽聲音**靠系統的螢幕錄音和語音辨識（中文、盡量在手機上辨識）。有的 App 不給錄音，或影片沒在播，就只拿得到畫面字幕，回答裡會註明。一次最多聽 180 秒。
- **核對微信號**要點開對方頭像讀資料頁，每次多花約 20–40 秒。
- **群聊總結**只能總結這台手機讀過、存下的訊息；沒盯著的群要它自己去翻。
- **GitHub／伺服器／激活碼**：設定和程式都做好了，等客戶給令牌和接口地址才能實測。不是 GET 的接口會先回「回覆確認才執行」，2 分鐘內有效。
