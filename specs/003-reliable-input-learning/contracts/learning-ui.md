# Learning UI contract

Home and Settings both link to Learning. The page shows the global switch, actual automatic/human lesson counts and uncertain/human-rated feedback count; lessons open details with source task/run, content, dates, reinforcement and reference count/last reference. Details can disable or delete a lesson and open an available source run. A missing source is explained. Recent review events have status and reason, with honest empty/disabled/error states. Viewing/navigation adds zero model requests. Changes affect future task contexts.
