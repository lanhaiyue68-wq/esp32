# build74 直接取屏试用

1. 安装桌面的 `Lan-Agent-build74-unsigned.ipa`，使用之前的签名工具和手机上原来的 bundle ID。IPA 未签名，不能直接点击安装；沿用原来的签名流程。
2. 打开 Lan Agent，保持现有开发板的无线连接。点首页“直接取屏”状态入口（或设置向导的取屏步骤）。
3. 选择“直接取屏”，点“开始共享整个屏幕”，在 iOS 系统选择器中授权**整个屏幕**。仅共享当前 App 会被拒绝。
4. 等预览出现和状态变成“整屏取屏中”。保持手机竖屏、解锁；不需要 AirPlay 镜像或 USB。若需要重新校准，继续使用原来的校准入口。
5. 重复 build73 的同一任务和模型配置。让 App 自行切到后台操作，不要手动切断系统共享。停止任务后，共享仍保留供下一次任务使用；需要结束共享时，在取屏页面点“停止屏幕共享”。
6. 导出日志 ZIP。比较是否真正完成、启动耗时、模型调用次数、帧龄、token、是否重复输入。新日志包含 `capture_source=direct`、系统版本、画面和确认帧龄。

## 失败时

- 显示仅当前 App：停止后重新选择整个屏幕。
- 显示系统限制：检查系统屏幕录制限制，并重新打开共享选择器。
- 显示画面过期/共享中断：任务会等待恢复；回取屏页面停止后重新共享整个屏幕。
- 横屏：恢复竖屏，等待新的完整画面。此预览版只支持项目原有的竖屏操作。
- 需要对照旧链路：停止任务、监听、校准和录制后，在同一页面选择“镜像回传”，再按原来的 AirPlay 流程连接。

## 验收边界

模拟器测试和 Release 编译不能证明用户 iPhone 上的系统授权、跨 App 后台取屏、指针可见性、无线点击和中文输入效果。这些需要安装后运行同一任务，并用导出日志验收。目前没有新旧版本成功任务的配对计时，不承诺提速倍数。

系统录屏的受保护区域可能不可见；系统报告 blank/suspended/stopped、过期画面或横屏时，程序不继续用旧图操作。直接取屏只在本地限速转换，沿用现有 Agent 的模型请求时机，不把每一帧上传云端。
